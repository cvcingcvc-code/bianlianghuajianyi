## 安装、复现、启动、停止

在仓库根目录，使用已有 Node.js 环境（项目当前Node 24）和 PowerShell 7。V2没有新增依赖。

```powershell
# 仅在尚未安装依赖时
npm ci

# 价格数据：官方2021–2025 ZIP，仅补不存在文件并校验
pwsh -NoProfile -File scripts/fetch-trend-grid.ps1
# V2独立资金费/标记价：60+36个官方ZIP和CHECKSUM
pwsh -NoProfile -File scripts/fetch-eth-v2.ps1

# 固定模型评估，每次写入新的时间戳目录（研究代码须已提交）
node scripts/eth-v2.js

# 选择刚生成的报告
$v2Report = (Get-ChildItem reports/eth-v2 -Directory | Sort-Object Name | Select-Object -Last 1).FullName + '/report.json'
node scripts/eth-v2.js --serve --report $v2Report --session default
```

浏览器打开 http://127.0.0.1:3002/ 。开始、暂停保存、推进四小时均为本地历史回放控制；默认暂停，不自动交易。Ctrl+C 停止服务；同一命令和session恢复上次持仓、待单、账本与游标。崩溃后下次启动校验快照并清除已死亡进程的锁。

新一轮演示换 `--session another-name`，不覆盖已有账户；同一session不能两个进程同时写。代码或数据指纹变化时拒绝恢复旧账户，使用新报告和新session。不要手改快照或删除校验绕过检查。
报告不与新代码静默混用，服务启动核验代码、数据和预测文件哈希。报告创建日期是2026不代表使用2026行情；加载器范围固定至2025年末，不提供覆盖范围的CLI选项。

本轮可直接使用的报告：
`reports/eth-v2/2026-09-22T04-33-01-552Z/report.json`。
初次报告也保留：`reports/eth-v2/2026-09-22T04-31-27-701Z/report.json`。
两次报告的 forecasts、fits、BASE/STRESS/基准四组账本SHA相同；第二次仅匹配CLI修复后的源码指纹，没有调整模型。
